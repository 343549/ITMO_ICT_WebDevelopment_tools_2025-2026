# Лабораторная работа №1

**Тема:** разработка серверной части веб-платформы для поиска людей в команду (FastAPI).

## Цель работы

Реализовать серверное приложение на FastAPI с:

- регистрацией и авторизацией пользователей;
- JWT-аутентификацией;
- хэшированием паролей;
- CRUD-операциями для предметной области;
- PostgreSQL и ORM (SQLAlchemy 2.0);
- миграциями Alembic;
- аннотацией типов и разделением кода по слоям.

## Предметная область

Платформа **Team Finder** предназначена для поиска партнёров в команды и совместной работы над проектами:

- пользователи создают профиль и указывают навыки;
- создают проекты и команды внутри них;
- управляют участниками команд и задачами.

## Используемые технологии

| Компонент | Технология |
|-----------|------------|
| Язык | Python 3.12+ |
| Фреймворк | FastAPI |
| ORM | SQLAlchemy 2.0 |
| СУБД | PostgreSQL (`psycopg`) |
| Миграции | Alembic |
| Аутентификация | JWT (`python-jose`) |
| Пароли | bcrypt |
| Локальная БД | Docker Compose |

## Структура проекта

```text
1lab/
  app/
    db/           # сессия и Base
    models/       # ORM-модели
    routes/       # эндпоинты
    schemas/      # Pydantic-схемы

    versions/
  docs/           # документация MkDocs

  requirements.txt
```

## Вывод

Реализовано серверное приложение с аутентификацией, безопасным хранением паролей, реляционной моделью из 7 таблиц, CRUD API, вложенными GET-ответами и миграциями Alembic. Проект готов к демонстрации на защите и к дальнейшему расширению.
